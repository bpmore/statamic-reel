## No warranty, and specifically no conformance claim

The capitals are below, as usual. This part is in plain words because it is the
part people actually need.

This Software cannot tell you that a video or audio file meets an
accessibility obligation, and nothing it produces is a conformance claim.
It reads caption files and reports what it can detect: a file a player will
not show correctly, a cue that reads too fast against a named standard, and
signals that a file was never corrected by a person. It cannot tell whether
a caption is accurate, whether a transcript is faithful, whether a video has
sound, or whether an audio description exists, and it says so in each case
rather than guessing. A problem it reports is a problem. A file it reports
nothing on has not been proven right.

Deciding whether media meets a legal or contractual accessibility obligation
is work for a person, and this Software does not do it, replace it, or
provide evidence sufficient for it.
