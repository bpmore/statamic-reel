# Real caption files

Files written by other people and other tools, kept so the engine is held to
what is actually out there rather than to fixtures written to pass.

Only files whose licence allows redistribution are here. The rest of the
five-file check the brief asks for was run locally and is recorded in
`docs/DECISIONS.md`.

| File | Origin | Licence |
| --- | --- | --- |
| `sintel-en.vtt` | English subtitles for Sintel, the Blender Foundation open movie, as served by MDN's video player example (iandevlin.github.io/mdn/video-player-with-captions). | CC BY 3.0, Blender Foundation |
| `videojs-example-captions.vtt` | `docs/examples/shared/example-captions.vtt` from the video.js repository. Has a real 39 ms overlap between its last two cues. | Apache 2.0, Brightcove |
